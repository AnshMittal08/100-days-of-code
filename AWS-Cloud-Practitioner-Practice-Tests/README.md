Three full-length, multiple-choice practice tests (50 questions each = 150
questions total) for the **AWS Certified Cloud Practitioner** exam, built to
mirror the official exam's domain weighting:

| Domain | Weight | Approx. Qs per 50-question test |
|---|---|---|
| 1. Cloud Concepts | 24% | 12 |
| 2. Security and Compliance | 30% | 15 |
| 3. Cloud Technology and Services | 34% | 17 |
| 4. Billing, Pricing, and Support | 12% | 6 |

## Interactive mock exam (recommended)

Prefer clicking over reading tables? Open [`mock-test.html`](mock-test.html)
in any browser — it's a single self-contained file, no server or install
required (download it and double-click, or open it directly from a local
clone). It turns the three tests above into a real mock-exam UI:

- **Exam Mode** — 90-minute countdown timer, answers hidden until you submit,
  a jump-to-any-question answer sheet, and flag-for-review — same shape as
  test day.
- **Practice Mode** — untimed, with instant right/wrong feedback and the
  explanation shown the moment you answer each question.
- A results screen with your overall score, a pass/fail call against the 72%
  benchmark, a score breakdown by domain, and a full question-by-question
  review (filterable to just the ones you missed or flagged).
- Progress autosaves to your browser's local storage, so closing the tab
  mid-attempt and picking it back up later just works.

## How to use these tests

1. Attempt a full test in one sitting (aim for ~90 minutes, same as the real
   exam) without looking at the answer key.
2. Most questions have a single correct answer; a few are marked
   **"(Choose TWO)"**, matching the real exam's multi-select format.
3. Grade yourself with the matching `-Answers.md` file — each answer includes
   a short explanation of *why* the correct option is right and, where
   useful, why the distractors are wrong.
4. A score of 80%+ (i.e., missing 10 or fewer of 50) is a good signal you're
   ready — the real exam pass mark is scaled, but ~72% is the commonly cited
   passing threshold.

## Topics covered

- Cloud computing concepts, benefits, and deployment/service models (IaaS,
  PaaS, SaaS)
- AWS global infrastructure (Regions, Availability Zones, Edge Locations)
- The AWS Well-Architected Framework and Cloud Adoption Framework (CAF)
- Shared Responsibility Model
- IAM (users, groups, roles, policies, MFA)
- Compute: EC2, Lambda, ECS/EKS, Elastic Beanstalk, Lightsail
- Storage: S3 (storage classes), EBS, EFS, Storage Gateway, Snow Family
- Databases: RDS, DynamoDB, Aurora, Redshift, ElastiCache
- Networking: VPC, Route 53, CloudFront, Direct Connect, ELB
- Management & monitoring: CloudWatch, CloudTrail, CloudFormation, Trusted
  Advisor, Config, Systems Manager
- Security services: GuardDuty, Inspector, KMS, Shield, WAF, Artifact,
  Secrets Manager
- Pricing models: On-Demand, Reserved Instances, Spot Instances, Savings
  Plans, Free Tier
- Billing & cost management: Cost Explorer, AWS Budgets, Cost and Usage
  Report, Consolidated Billing, AWS Organizations
- Support plans (Basic, Developer, Business, Enterprise On-Ramp, Enterprise)

Good luck with your exam!
